Appointment (OPD)

oeHealth appointment feature is available for both doctors and patients to manage their own checkup schedules.

It is also tightly integrated with Odoo's calendar control so they will be always updated for your upcoming schedules.

Prescriptions

Generate prescriptions easily by listing the required medicines with dosage information and frequency for consumption.

Create invoice for the generated prescription to be sent to in-house pharmacy and accounts department and send as an email directly to patient.

Inpatient Admission (IPD)

Manage admission procedure of your patients with super easy inpatient hospitalization process, wards and beds reservations.

The doctor can add therapeutic diets, nursing, and discharge plan information in the system to perform the effective treatment.

The module also allows doctor or health center administrative team to automatically raise payment notification at the time of patient discharge.

Accounting & Invoicing

oeHealth is tightly integrated with Odoo's default Accounting & Invoicing features.

You can easily raise invoices for different services like Doctor's consultations, Prescriptions, Lab test & Inpatient admissions directly from the app and manage different accounting tasks of your health center.

Dynamic Settings

Management of most important oeHealth operations through centralized settings option available under Odoo's General Settings panel.

REST API

oeHealth REST API is a fully customizable REST API Connector for the oeHealth Android Mobile Apps. oeHealth Mobile is an Android based app available for both Patients & Doctors and allows to access important information directly from the mobile phones.

Secure Access

API has routes to authenticate and retrieve a token on every call to securely transfer the required information between your Odoo server and oeHealth Mobile app.

View & Manage Important Details

Allow users to access information like Upcoming Appointments, Assigned Prescription & Labtests, View or update account details and many more.

Cross Platform Compatibility

Patient or Doctor can access their account information anytime & anywhere on Desktop, Tablets or Android phones without any hassle.

Push Notifications

API will automatically notify users using push notification message on their phone before 1 hour in advance for their upcoming treatment visit appointments.

Fully Customizable

Completely scalable to easily support oeHealth Mobile app customization. It also provides flexibility to exchange oeHealth data with third party API & systems.

Clear Documentation

The module is shipped with detailed documentation containing information about API configuration and all the end points.
