Odoo 18 Delivery Plan (Enterprise)

The module enables delivery planning based on priority.

Note: This module is tested and working in Odoo Enterprise edition but not tested in community version. And we are supporting Ubuntu OS and not Windows OS.

Note

  • Used Leaflet JavaScript library for interactive maps.
  • Before installing the module, install the following Python package:
    1. pip install geopy

How to use

  • Choose a map.


  • Click on Delivery route menu.


  • By clicking on "Delivery route" menu user can see the customer delivery of choosen date and selected map as well.


  • User can see the products of delivery order.


  • Select the warehouse from "Warehouse".


  • After Selecting the order, click on process.
  • Route shown on map and proirity as well based on shortest path.
  • If selected map is Leaflet then view


  • If selected map is Google


  • By clicking on assign button user can assign delivery person from the popup.


  • After click on assign, delivery person can found assigned delivery orders under assigned delivery orders menu.
