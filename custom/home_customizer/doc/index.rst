Home Screen Icon Layout
======================

The Home Screen Icon Layout module provides a powerful set of tools for users to personalize their Odoo home screen experience. 

Features
--------

*   **Custom Grid Layout**: Define the number of columns in the app drawer.
*   **Icon Customization**: Adjust icon size, corner radius, and spacing.
*   **Typography Control**: Scale the text size of app labels.
*   **Real-time Preview**: See changes instantly in a preview mode before applying them globally.
*   **User-Specific**: Each user can have their own unique layout settings.
*   **Systray Integration**: Quick access to appearance settings from the top menu bar.

Configuration
-------------

Once installed, a new paintbrush icon will appear in the systray (top right corner). 
Users can click this icon to open the customization modal and adjust their preferences.
