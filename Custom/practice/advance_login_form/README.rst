Login Page Customizer | Custom Background, Style & Branding
================================================================

The **Login Page Customizer | Custom Background, Style & Branding** Odoo module extends the default Odoo login page with a rich set of customization options, including background images, custom color themes, and form alignment controls. This module is designed to help organizations deliver a branded, secure, and user-friendly login experience.

**Table of Contents**

.. contents::
   :local:

**Key Features**
================================================================

- **Background Image**: In the settings, users can add a custom image to be used as the background image for the login page, giving it a personalized and professional appearance.
- **Alignment Control**: Choose the alignment of the login form — center, left, or right — to match your organization's layout preferences.
- **Custom Colors**: Customize the look and feel of the login page by selecting text color, button color, login button hover color, and login form background color.
- **Password Strength Requirement**: Passwords must be at least 8 characters long and contain at least one lowercase letter, one uppercase letter, one digit, and one special character.

**Summary**
================================================================

With the **Login Page Customizer | Custom Background, Style & Branding** Odoo module, organizations can fully customize the Odoo login page to reflect their brand identity while improving security through enforced password policies. The module offers an intuitive settings interface for managing all customization options without any code changes.

**Installation**
================================================================

1. Clone or download the module from the repository.
2. Place the module in your Odoo addons directory.
3. Restart the Odoo server to update the app list.
4. Install the **Login Page Customizer | Custom Background, Style & Branding** module from the Odoo Apps menu.

**How to Use This Module**
================================================================

1. **Background Image**: Go to Settings → Login Form Settings. Upload a custom background image for the login page.
2. **Alignment**: Select the desired alignment (center, left, or right) for the login form from the settings.
3. **Custom Colors**: Choose your preferred colors for text, buttons, hover states, and the form background.
4. **Password Strength**: When setting or resetting a password, ensure it meets the strength requirements: 8+ characters, with uppercase, lowercase, digit, and special character.
